# 🐧 Automações e Scripts em Shell (Linux)

Repositório contendo uma série de scripts desenvolvidos para práticas de administração de sistemas, manipulação de arquivos e automação de tarefas no Linux.

## 📋 Índice de Scripts

| Arquivo | Descrição / Funcionalidade |
| :--- | :--- |
| [`script01.sh`](./script01.sh) | Calculadora interativa com menu para operações básicas e tratamento de opções inválidas. |
| [`script02.sh`](./script02.sh) | Remoção segura de arquivos com verificação prévia de existência no sistema. |
| [`script03.sh`](./script03.sh) | Renomeação de arquivos utilizando o comando `mv` com validação de origem. |
| [`script04.sh`](./script04.sh) | Movimentação de arquivos entre diretórios com mensagem de confirmação. |
| [`script05.sh`](./script05.sh) | Verificação da existência de um usuário no sistema consultando o arquivo `/etc/passwd`. |
| [`script06.sh`](./script06.sh) | Pesquisa de uma palavra ou string específica dentro de um arquivo usando o `grep`. |
| [`script07.sh`](./script07.sh) | Menu interativo de busca de arquivos ou comandos utilizando `find`, `whereis` ou `locate`. |
| [`script08.sh`](./script08.sh) | Concatenação de dois arquivos em um terceiro (com suporte a append via `>>`). |
| [`script09.sh`](./script09.sh) | Comparação de conteúdos entre dois arquivos utilizando o comando `diff`. |
| [`script10.sh`](./script10.sh) | Consulta de informações detalhadas de um usuário (pasta home e espaço em disco). |
| [`script11.sh`](./script11.sh) | Exibição dos usuários conectados ao sistema (`who`) com opção de detalhamento. |
| [`script12.sh`](./script12.sh) | Alteração interativa de permissões de arquivos usando o comando `chmod`. |
| [`script13.sh`](./script13.sh) | Listagem detalhada dos processos em execução no sistema (`ps aux`). |
| [`script14.sh`](./script14.sh) | Pesquisa por processos específicos em execução combinando `ps` e `grep`. |
| [`script15.sh`](./script15.sh) | Encerramento seguro de processos via PID utilizando o comando `kill` com confirmação. |
| [`script16.sh`](./script16.sh) | Exibição organizada de informações e versão do kernel do sistema (`uname`). |
| [`script17.sh`](./script17.sh) | Contagem de linhas, palavras e caracteres de um arquivo utilizando o `wc`. |
| [`script18.sh`](./script18.sh) | Painel informativo com data, versão do kernel, calendário e tempo de atividade (`uptime`). |
| [`script19.sh`](./script19.sh) | Menu unificado de informações e monitoramento geral do sistema. |
| [`script20.sh`](./script20.sh) | Menu completo de gerenciamento e manipulação de arquivos. |
